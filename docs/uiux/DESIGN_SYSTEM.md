# Design system

Tokens live in `resources/js/precision.css`, loaded after existing styles.

| Meaning | Light | Dark |
| --- | --- | --- |
| App background | `#F5F7FC` | `#080F20` |
| Surface | `#FFFFFF` | `#101E37` |
| Primary action | `#245BFF` | `#4B78FF` |
| Inflow / success | `#008F65` | `#42D69F` |
| Outflow / danger | `#E22D47` | `#FF6A7E` |
| Text | `#101827` | `#F8FAFF` |
| Secondary text | `#536078` | `#B6C6DE` |
| Border | `#DCE3EF` | `#263955` |

Use color for meaning and pair it with labels/icons. Interactive controls have a 44px minimum where the shared responsive layer applies. Focus uses cyan. Surfaces are mostly solid, with restrained borders and shadows. The dashboard balance hero is deep navy in both themes. Reduced motion is respected globally.
