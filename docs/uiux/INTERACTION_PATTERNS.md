# Interaction patterns

- Navigation links show active state and current-page semantics.
- Catat opens four task choices; transaction type is conveyed in the route query and is preselected by the existing form. The amount field receives autofocus on entry.
- Scan navigates to the existing import flow.
- Lainnya opens the full secondary navigation sheet; selecting a destination closes the sheet.
- Account privacy and transaction save feedback remain in the existing dashboard and form flows.
- Inputs retain their existing validation and submit behavior; shared styles improve target height, focus, and contrast.

No new financial calculations or advice are introduced. Failure recovery continues to use existing per-view error handling and notification behavior.
