# Perbandingan visual

## Perubahan struktural

- Beranda sebelumnya memuat lima kartu metrik seragam dan panel insight dekoratif. Beranda baru menggabungkan saldo operasional sebagai fokus, membandingkan selisih pemasukan/pengeluaran sekali, lalu memberi tiga jalan ke rencana dan aset. Grafik dan transaksi menjadi bukti yang dapat ditelusuri.
- Aksi utama pada beranda sekarang empat tindakan konkret. Ponsel tetap memakai sheet untuk Catat agar jenis pengeluaran/pemasukan/transfer tidak tercampur.
- Komponen pemberitahuan sekarang memakai ikon vektor, tombol tutup berlabel, dan transisi tanpa `transition: all`.
- Pass referensi Stitch menyatukan semua route ke kanvas midnight, material liquid glass, dan sinyal emerald/cyan/koral. Hasilnya mencakup shell desktop/mobile, menu, komponen form, tabel, dialog, toast, auth, serta ringkasan finansial.
- Layar beranda referensi memberi pola hierarchy untuk saldo, sinyal perhatian, ritme arus kas, target, dan aktivitas; implementasi memakai data dan status aktual Cashlog, tidak menambahkan angka demo.
