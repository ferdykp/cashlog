# Cashlog Web

SPA Vue 3 untuk Cashlog. Panduan setup dan konfigurasi API ada di [README utama](../README.md).

## Perintah

```sh
npm install
npm run dev
```

Atur `VITE_API_BASE_URL` agar menunjuk ke API Laravel. Untuk pemeriksaan frontend gunakan `npm test` dan `npm run build`.

Komponen dan tampilan ada di `src/components/` dan `src/views/`; logika lintas layar berada di `src/composables/`.
